# EXP-2-PROMPT-ENGINEERING-

## Aim: 
Comparative Analysis of different types of Prompting patterns and explain with Various Test Scenarios

Experiment:
Test and compare how different pattern models respond to various prompts (broad or unstructured) versus basic prompts (clearer and more refined) across multiple scenarios. 
Analyze the quality, accuracy, and depth of the generated responses.


## Algorithm:


Step 1: Define Scenarios
Select multiple test scenarios across domains (e.g., creative writing, technical explanation, data analysis, healthcare, business, education).

Step 2: Design Prompts
For each scenario s
Create a Broad Prompt (vague, minimal constraints).
Create a Refined Prompt (role, task, constraints, format).

Step 3: Generate Responses
For each prompt type p∈P:
Input prompt into the model.
Collect generated response R
i,p.

Step 4: Evaluate Responses
Define evaluation metrics:
Quality (clarity, structure, usefulness)
Accuracy (correctness, reliability)
Depth (detail, completeness)

Score each response on a scale of 1–10.


Step 5: Compare Results
For each scenario:
Compare Broad vs Refined scores.
Identify which prompt performs better.

Step 6: Aggregate Analysis

Compute average scores:AvgQ , AvgA , AvgD
	​
Calculate improvement:
Improvement=Refined−Broad

Step 7: Interpret Findings
Analyze patterns:
Does refinement improve consistency?
Which domains benefit most?
Identify weaknesses of broad prompts.

Step 8: Draw Conclusions
Summarize insights:
Refined prompts improve quality, accuracy, and depth significantly.
Highlight best practices (role assignment, constraints, context).

Step 9: Recommend Improvements
Suggest:
Use structured prompts
Add context and constraints
Iterate prompts for better results

## Output


## Result

Refined, structured prompts lead to clearer, more accurate, and context-sensitive AI outputs in software testing scenarios. This shows the importance of precise prompt design in improving quality and usefulness in practical AI-assisted testing.
